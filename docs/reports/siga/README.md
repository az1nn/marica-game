## Canonical rendering contract

The authoritative default report pattern is now:

~~~text

~~~

That skill defines the stable dashboard layout, topics, palette, factuality rules and live-state reconciliation required for every new Maricá Game report.

The canonical topic order is:

1. Header;
2. Estado Global;
3. Repositório;
4. Maricá / Animal-First visual identity;
5. Fluxo SIGA;
6. Unidade atual / última unidade verificada;
7. Gates exato-head;
8. Tarefas da fase atual;
9. Próxima ação;
10. Footer source.

Images stored here are visual references only. They never override live repository state, specs, tasks, claims, PRs, handoffs or exact-head CI evidence.

A previous report must never be reused as state input for a new report.
