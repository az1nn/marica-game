# G447 — Offline Return Contract

Resume an existing validated local v1 profile after 3 hours, replay at the same timestamp, then 4 days, rollback, then 1 hour, across seven independent Godot OS processes sharing `user://`. Use G423 logical time and G441 revision CAS; G442 staged save and G444 typed pet hydration. Elapsed is reported exactly once on each successful new observation; same/older clock does not write, preserving revision, animal snapshots and G445 ledger. Invalid clocks fail closed. Mutation changes elapsed to zero and MUST fail hours, then restored source passes. No network APIs. This certifies persisted observation only, **not** automatic hunger, health, lifecycle, crops or farm progression; those are later gameplay gates. No wall-clock authenticity or concurrent multi-process transaction guarantee.
